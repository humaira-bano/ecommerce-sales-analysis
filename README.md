# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data using MySQL to identify sales trends, top-performing products, customer spending patterns, and category performance.

## Tools & Technologies
- MySQL
- SQL

## Analysis Performed
- Total revenue and orders
- Top-selling products
- Product-wise revenue
- Category-wise sales
- Customer-wise spending
- Monthly sales
- Average order value
- Customer ranking
- Repeat customers
- City-wise sales

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- JOINs
- Aggregate functions
- CASE
- Subqueries
- CTEs
- Window functions

## Key Insights
The analysis identifies the highest-revenue products, best-performing categories, highest-spending customers, and overall sales patterns.

## Project Files
- `ecommerce_analysis.sql` — SQL database, tables, data and analysis queries
- `business_insights.txt` — Business insights from the analysis
